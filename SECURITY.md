# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.4.x   | :white_check_mark: |
| < 1.4   | :x:                |

## Reporting a Vulnerability

If you discover a security issue or vulnerability, please do not open a public issue.
Report it responsibly via GitHub Private Vulnerability Reporting or contact the maintainers directly.
