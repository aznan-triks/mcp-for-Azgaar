# Uninstall and Cleanup Guide

> **Tested on:** Windows 10 with Google Chrome and a stdio MCP client. macOS, Linux, Microsoft Edge alone and the other AI programs named here follow the same standards and the installer is written for them, but they have not been tested yet.

This guide explains how to disconnect mcp-for-Azgaar from your AI clients, preserve your personal maps, and completely remove the project from your computer.

## Step 1: Disconnect from AI Clients

Before deleting the project folder, remove the server registration from your AI programs so they do not attempt to start a missing tool.

### Automatic Removal for JSON-Based Clients

If you used `npm run register --write` during setup, you can remove the server automatically using the `--remove` flag:

| AI Program | Command to Remove | Settings File Modified |
|---|---|---|
| Claude Desktop | `npm run register -- --desktop --remove` | `claude_desktop_config.json` |
| Cline (VS Code) | `npm run register -- --client cline --remove` | `cline_mcp_settings.json` |
| Cursor | `npm run register -- --client cursor --remove` | `~/.cursor/mcp.json` |
| Gemini CLI | `npm run register -- --client gemini --remove` | `~/.gemini/settings.json` |
| LM Studio | `npm run register -- --client lmstudio --remove` | `~/.lmstudio/mcp.json` |
| Zed | `npm run register -- --client zed --remove` | `settings.json` (`context_servers`) |

The tool makes a backup of your configuration file before modifying it (saved with extension `.bak-<timestamp>`).

### Manual Removal for Other AI Programs

For programs that do not use standard JSON settings, remove the entry by running a command or editing the configuration file by hand:

#### Claude Code (CLI)
Run the following command in your terminal:
```bash
claude mcp remove azgaar
```

#### OpenAI Codex CLI
Open `~/.codex/config.toml` in a text editor and delete the `[mcp_servers.azgaar]` section:
```toml
# Delete these lines:
[mcp_servers.azgaar]
command = "..."
args = [...]
```

#### Hermes Agent (Nous Research)
Open `~/.hermes/config.yaml` in a text editor and delete the `azgaar` block under `mcp_servers`:
```yaml
# Delete these lines under mcp_servers:
  azgaar:
    command: "..."
    args:
      - "..."
```

#### Continue.dev
Open `~/.continue/config.yaml` in a text editor and remove the `azgaar` item from `mcpServers`:
```yaml
# Delete this entry under mcpServers:
  - name: azgaar
    command: "..."
    args:
      - "..."
```

After removing the configuration, restart your AI application.

## Step 2: Preserve Your Maps and Exports (Optional)

The project directory contains your own creative work:

- `maps/`: Contains your saved map files (`.map`) and the last automatic session save (`autosave.map`).
- `exports/`: Contains exported pictures (PNG, SVG, JPEG), GeoJSON files, and CSV spreadsheets generated by the AI.

If you want to keep your maps and exported assets, copy the `maps/` and `exports/` folders to a safe location (such as your `Documents` folder) before proceeding.

## Step 3: Delete the Project Folder

Once registrations are removed and your data is backed up:

1. Close any running copies of your AI client and any browser window opened by the tool.
2. Delete the entire `mcp-for-Azgaar` project folder from your disk.

All temporary browser profiles (`.browser-profile`), downloaded upstream source files (`upstream/`), and dependencies (`node_modules/`) are contained inside this folder and will be removed.

## Node.js and Browser Components

Deleting the project folder does not uninstall Node.js or your web browsers (Google Chrome or Microsoft Edge).

- **Google Chrome / Microsoft Edge**: You can continue using your browser normally.
- **Node.js**: If you installed Node.js solely for mcp-for-Azgaar and no longer need it:
  - On Windows: Open **Start** > **Settings** > **Apps** > **Installed apps**, locate **Node.js**, click the three dots, and select **Uninstall**.
  - On Windows via terminal: Run `winget uninstall OpenJS.NodeJS.LTS`.
  - On macOS / Linux (not tested): remove Node.js using your package manager (for example `brew uninstall node` or `sudo apt remove nodejs`).

## How to Update or Reinstall Without Losing Maps

You do not need to delete everything when updating or fixing an installation.

### Updating Azgaar
To update Azgaar to the latest release without losing any maps or settings:
1. Double-click `update.bat` (or run `npm run update` in a terminal).
2. The updater downloads the new version, tests it alongside the current one, and only switches if all compatibility tests pass.
3. Your `maps/` and `config/` folders are never touched by updates.

### Clean Reinstall from Scratch
If you want to reset the project completely while preserving your maps:
1. Make a backup copy of your `maps/` directory and your `config/fmg-mcp.json` file.
2. Delete the project folder or run `git clean -fdx` (if using git).
3. Extract or clone a fresh copy of mcp-for-Azgaar.
4. Copy your backed-up `maps/` directory and `config/fmg-mcp.json` file into the new project root.
5. Double-click `install.bat` (or run `npm install` and `npm run setup`). All your maps will be available immediately.
