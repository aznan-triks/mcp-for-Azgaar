# Bundled fonts

Latin subset, weight 400, taken from the `@fontsource/*` npm packages (SIL Open Font License 1.1; each licence text is in `licenses/`).
The default build of Azgaar loads the same families from fonts.gstatic.com; they are bundled here so the map works offline.
